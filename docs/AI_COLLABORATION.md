# Human–AI collaboration

## How I work with AI

RealmNode began with a question I kept running into: why should a persistent world depend on one server that someone has to own and pay for? The idea, the direction and the decisions are mine. AI helps me think it through, write it down and, later, build and test it. Coding agents work directly in the repositories: they research, draft documents, write code and run tests, while I decide what to build and what works.

Two rules hold this record together. Work is credited to whoever did it: the story is told in my voice, but when AI wrote a document or code, the record says so and names the tool and, where it is known, the model. And a plan is not a result: proposed, accepted, built, tested and published stay separate.
